# Alan K Biju — Personal Portfolio

A minimal, responsive static portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract `personal_portfolio.zip` if you downloaded the ZIP.
2. Open the `personal_portfolio` folder.
3. Double-click `index.html` to open it in your browser.

No build tools or server are required. For live reload while editing, open the folder in VS Code and use the Live Server extension.

## Customize before publishing
- In `index.html`, replace `your.email@example.com` in the email link with your real email address.
- Add your GitHub, LinkedIn, and project repository links if desired.
- Check all skills and project descriptions for accuracy.
- Google Fonts load from the internet; system fonts will be used if offline.
